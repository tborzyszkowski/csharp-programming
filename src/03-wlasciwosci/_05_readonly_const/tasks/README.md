# Zadania - Readonly vs Const

## 📝 Zadanie 1: Const vs Readonly

Stwórz klasy `MathLib` (const) i `AppConfig` (readonly).

```csharp
// Const
public const double GOLDEN_RATIO = 1.618;

// Readonly
public readonly string AppName;
```

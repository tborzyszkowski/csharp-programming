## 💡 Kluczowe Koncepty Omówione

### Temat 1: Właściwości vs Pola
- Enkapsulacja - dlaczego właściwości > pola
- Gettery i settery
- Read-only i write-only properties
- Backing fields

### Temat 2: Auto Properties
- `{ get; set; }` - automatyczne backing fields
- Inicjalizacja wartości domyślnych
- Asymetryczne accessory: `public get; private set;`

### Temat 3: Walidacja Właściwości
- Backing field pattern
- Throw exceptions vs silent ignore
- PropertyChanged events
- Fail-fast principle

### Temat 4: Indeksatory
- `this[int]` - sekwencyjne indeksatory
- `this[string]` - indeksatory po nazwach
- `this[row, col]` - wielowymiarowe
- Tablice asocjacyjne

### Temat 5: Readonly vs Const
- `const` - stałe czasu kompilacji
- `readonly` - stałe czasu runtime
- `static readonly` - singleton pattern
- Readonly collections

### Temat 6: Init Properties (C# 9+)
- `{ get; init; }` - immutable properties
- `required` keyword (C# 11+)
- DTOs z gwarancją initialization
- Kombinacja init + required

### Temat 7: Nullable Reference Types (C# 8+)
- `string?` - nullable vs non-nullable
- Null-safety - compile-time checking
- Null-coalescing `??`
- Null-safe `?.` operator
- Nullable value types `int?`
